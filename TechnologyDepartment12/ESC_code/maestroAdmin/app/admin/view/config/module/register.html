注册配置

account_rule：可选手机号或者邮箱注册状态。

is_show_user_protocol：用户协议和隐私协议是否显示。

register_give_money：注册赠送金额。

reg_ip_limit：同IP可注册账号个数限制

is_repeat_password：注册时是否开启重复一遍密码（登录密码及安全密码）。

is_verify_email_code：邮箱注册时是否需要验证邮箱验证码。

is_verify_phone_code：手机注册时是否需要验证手机验证码。

verify_code_ttl：验证码有效时间，单位秒。

open_region_limit：填1为开启，0为关闭

多个请用英文逗号[,]分隔

多个请用英文逗号[,]分隔
禁止权重高于允许权重
禁止和允许只能设置一个

查询

输入IP可查询以下信息
国家代码[countryCode]:{$ip_local.countryCode|default='-'}
国家名称[countryName]:{$ip_local['countryName']|default='-'}
省/区级名称[regionName]:{$ip_local['regionName']|default='-'}
城市名称[cityName]:{$ip_local['cityName']|default='-'}

邀请配置

invite_code_required：邀请码可选择是否必填。

recharge_num_valid_user：用户充值多少金额为有效用户。

登录配置

error_to_ban：连续输入几次错误的密码封停账号登录权限。

实名认证

auto_real_name_auth：自动审核实名认证。
