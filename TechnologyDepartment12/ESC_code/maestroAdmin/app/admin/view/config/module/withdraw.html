虚拟币出款地址

payment_wallet：出款账户地址

trx_payment_wallet：TRX出款账户地址

bsc_payment_wallet：bsc出款账户地址

提现基础设置

withdraw_open：提现开关。

is_repeat_withdraw_address：客户取款地址是否能重复。

first_withdraw_input_contact：第一次提现是否要求输入联系方式。

first_withdraw_is_min：第一次提现是否单独设置最低金额。

first_withdraw_min_money：第一次提现最低提现金额。

withdraw_check_hour：出款审核时间(小时), 通过审核后才能出款。

day_tx_count：填0时为不限制提现次数

withdraw_no_auth_times：填0时所有提现都需要审核

withdraw_need_kyc：提现是否需要实名认证。

vip0_is_withdraw：vip0是否可以提现。

withdraw_water_limit：提现流水限制 设置百分比数据（例如 10% 设置 10 ）

出款金额设置

auto_payment：是否自动出款。

auto_payment_safety_value：自动出款金额安全值,当出款金额大于该值时,需要后台人工审核出款。

min_withdraw_config：最小提现金额配置，选择全局由充值币种菜单配置控制，选择局部由vip配置菜单里控制。

withdrawal_100_multiple：整百金额提现。

today_recharge_withdraw_rate_warning：当日充提比例提醒，当日有充值，提现超过当日充值百分百提醒 设置百分比数据（例如 10% 设置 10 ）

free_withdraw_fee_num：单日免手续费笔数

withdraw_fee_min：最小手续费，单位{$config.fiat_currency_unit}。

withdraw_fee_max：最大手续费，单位{$config.fiat_currency_unit}。

withdraw_rate：提现手续费百分比。

withdraw_rate_method：手续费扣除方式。
