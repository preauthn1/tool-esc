交易量信用分

credit_score_trade_num：总分_多少交易量加一分（例如:30_200）

credit_score_active_num：总分:分值范围_m人加n分:分值范围_m人加n分（例如:40:0-20_1_10:21-30_2_5:31-40_3_6）

credit_score_new_num：总分:前n人_每人加m分（例如:30:5_3）

credit_score_overdue：时长(小时）:扣分值_时长:扣分值（例如:24:5_36:20）,最多四组

credit_score_times：倍数:最小分值-最大分值_倍数:最小分值-最大分值（例如: 1:50-59_2:60-69）
